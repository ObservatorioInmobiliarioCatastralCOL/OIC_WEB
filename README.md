# OIC_WEB - Observatorio Inmobiliario Catastral de Colombia

Repositorio de datos de acceso público del **Observatorio Inmobiliario Catastral (OIC)** del IGAC. Contiene los archivos de soporte para los tableros de información publicados en la página web del observatorio.

## Contenido

| Carpeta | Descripción |
|---------|-------------|
| `Informacion_Disponible/` | Bases de consulta de información disponible |
| `Transacciones_Inmobiliarias/` | Reportes, diccionarios de datos, metadatos y tablas de transacciones inmobiliarias (2015-2025) |
| `Intensidad_Dinamica_Inmobiliaria/` | Datos de intensidad y dinámica inmobiliaria |

## Nota sobre archivos grandes

Este repositorio utiliza [Git LFS](https://git-lfs.github.com) para gestionar archivos que superan el límite de tamaño de GitHub.
